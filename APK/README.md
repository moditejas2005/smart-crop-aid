## Installation Instructions

### Step 1: Download
Download the `Smart Crop Aid.apk` file to your Android device.

### Step 2: Enable Unknown Sources
Before installing, you need to allow installation from unknown sources:

**Method 1: Before Installation**
1. Go to **Settings** → **Security**
2. Enable **Unknown Sources** or **Install unknown apps**

**Method 2: During Installation**
1. When you tap the APK file, you'll see a security warning
2. Tap **Settings**
3. Enable **Allow from this source**
4. Go back and tap **Install**

### Step 3: Install
1. Locate the downloaded APK file in your **Downloads** folder
2. Tap on `Smart Crop Aid.apk`
3. Tap **Install**
4. Wait for installation to complete

### Step 4: Launch
1. Tap **Open** after installation
2. Or find **Smart Crop Aid** in your app drawer

## Troubleshooting

### Installation Blocked
**Problem**: "Install blocked" or "For security reasons..."  
**Solution**: Enable "Unknown Sources" in Settings → Security

### App Won't Open
**Problem**: App crashes on launch  
**Solution**: 
1. Clear app cache: Settings → Apps → Smart Crop Aid → Clear Cache
2. Reinstall the APK

### Features Not Working
**Problem**: Pest detection or other features fail  
**Solution**: 
1. Check internet connection
2. Grant required permissions (Camera, Location, Storage)
3. Restart the app

### Login Issues
**Problem**: Can't log in  
**Solution**: 
1. Ensure you're using the correct email and password
2. Check internet connection
3. Try resetting your password or creating a new account
